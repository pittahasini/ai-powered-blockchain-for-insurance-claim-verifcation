# AI Powered Blockchain Insurance Claim Verification

An AI-powered insurance claim verification system built using Flask, Machine Learning, OpenCV, and Blockchain concepts.

## Features

* Fraud risk prediction using Random Forest
* Vehicle and crop damage detection using OpenCV
* Blockchain-based claim storage
* Interactive analytics dashboard
* Insurance claim management system

## Technologies Used

* Python
* Flask
* OpenCV
* Scikit-learn
* HTML/CSS/JavaScript
* Chart.js

## Future Improvements

* Real blockchain integration
* Deep learning fraud detection
* Database integration
* User authentication
